## Intent and context

This is the serial release step for package 0.1.15 -> 0.1.16. It runs after every content change, because the digests cover all package files.

Follow the release precedent in `impl-plans/completed/wave-release.md` and `impl-plans/completed/gate-routing-release.md`.

## Non-goals

- Do not edit package content files (scripts, prompts, mocks, docs, tests). If a check fails because of content, report it as a finding for the owning plan instead of fixing it here.
- Do not push, install packages or touch `~/.riela`.

## File-level changes

1. In `packages/opus-terra-design-and-implement-review-loop/riela-package.json`, set `version` to `0.1.16`. Then run the digest update script. Do not hand-edit digests.
2. Regenerate `registry-index.json` with `mise run package:generate-index`. Do not hand-edit it.

## Pitfalls

- Delete every `__pycache__` before `package validate` and `check-digests`. Running the unit tests creates them, and a leftover one causes `CHECKSUM_MISMATCH`. If any content changes, rerun the digests and the index.
- Keep the order: tests -> workflow validate -> digests -> index -> pycache cleanup -> validate -> check-digests -> check-index.

## Done criteria

- Every verification command exits 0. `package validate` JSON reports `valid: true`.
- Add a dated `## Progress` section to this file with each command's exit status.
